PLANNER SEMANAL DA LUZIANA — APP INSTALÁVEL

Inclui:
- Capa e páginas de segunda a sexta.
- Checkboxes realmente clicáveis.
- Checkboxes salvos no aparelho.
- Reset automático no início de uma nova semana.
- Funcionamento offline após o primeiro carregamento.
- Manifesto e service worker para instalação como PWA.

Para instalar:
1. Publique esta pasta em um endereço HTTPS.
2. Abra no Chrome/Edge do celular.
3. Use o botão "Instalar" ou o menu do navegador > Adicionar à tela inicial.

Importante: abrir o index.html diretamente como arquivo local não habilita a instalação PWA; é necessário HTTPS (ou localhost para testes).
